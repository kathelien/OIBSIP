# OIBSIP - Task 4: Sentiment Analysis

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify text into Positive, Negative, and Neutral sentiment categories.

## Objective
To analyse text data and identify sentiment using machine learning classifiers.

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- NLTK
- Matplotlib
- Seaborn
- WordCloud
- Google Colab

## Dataset
Twitter Entity Sentiment Analysis dataset from Kaggle.

Dataset link:
https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis

## Methodology
1. Load and explore the dataset.
2. Preprocess the text data.
3. Extract features using TF-IDF.
4. Split data into training and testing sets (80:20).
5. Train Naive Bayes and Logistic Regression classifiers.
6. Evaluate accuracy, precision, recall, F1-score, and confusion matrices.
7. Visualise sentiment distribution and WordClouds.
8. Analyse misclassified examples.

## Results
The model evaluation results and best-performing classifier are reported in the project notebook.

## Applications
- Customer feedback analysis
- Product review analysis
- Social media sentiment monitoring

## How to Run
Open the notebook in Google Colab, upload the training CSV dataset, and run the cells in order.
