# OIBSIP - Task 3: Data Cleaning

## 📌 Project Overview
This project focuses on cleaning and preparing raw data for further analysis. Data cleaning is an important step in the data analytics process because it improves data quality, consistency, and reliability.

## 🎯 Objective
The main objective of this task is to identify and handle missing values, remove duplicate records, correct data inconsistencies, and prepare the dataset for analysis.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Jupyter Notebook / Google Colab

## 📂 Project Workflow
1. Load the dataset.
2. Explore the dataset structure and data types.
3. Identify missing or null values.
4. Check for duplicate records.
5. Handle missing values and duplicates where appropriate.
6. Correct data inconsistencies.
7. Verify the cleaned dataset.
8. Save the cleaned dataset for further analysis.

## 📊 Key Outcomes
- Improved data quality.
- Better consistency in the dataset.
- Identification and handling of data quality issues.
- A cleaned dataset ready for further analysis.

## 📁 Project Files
- `Data_Cleaning.ipynb` – Notebook containing the data cleaning process.
- `cleaned_dataset.csv` – Cleaned dataset, if generated.

## ▶️ How to Run
1. Download or open the project notebook.
2. Upload the original dataset to Google Colab or Jupyter Notebook.
3. Run the notebook cells in order.
4. Review the cleaning steps and output.
5. Download the cleaned dataset if generated.
